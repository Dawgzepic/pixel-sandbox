# Pixel Sandbox

A retro falling-sand toy for a phone browser. Glass dishes, water, stone, metal, and fire share one grid. Heat passes through glass. Warmer and Cooler change the temperature of whatever is already there. Fire does not melt glass; lava does, after a long contact. Fire melts stone and metal if you hold it; water hardens them back.

Play it at <https://dawgzepic.github.io/pixel-sandbox/>. It installs from Chrome and keeps working offline.

```bash
npm install
npm test
npm run dev
npm run build
npm run test:e2e
```

Paint with one finger. Pinch with two fingers to look closer. The bottom row is the quick palette; ALL opens every element.
