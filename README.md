# Pixel Sandbox

A retro falling-sand toy for a phone browser. Glass dishes, acid, base, fire, and a handful of wooden objects share one grid. Acid and base make salt and warm water. Acid fizzes on metal and leaves glass alone. Heat passes through glass. Fire melts stone, metal, and glass; water hardens them back.

Play it at <https://dawgzepic.github.io/pixel-sandbox/>. It installs from Chrome and keeps working offline.

```bash
npm install
npm test
npm run dev
npm run build
npm run test:e2e
```

Paint with one finger. Pinch with two fingers to look closer. The bottom row is the quick palette; ALL opens every element.
